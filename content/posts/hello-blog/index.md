홈페이지 한쪽에 있던 블로그를 `blog.seolcoding.com`으로 따로 열었습니다.

## 여기에 쓸 것

- AI 교육 현장에서 받은 질문과 답
- 바이브코딩으로 실제 문제를 푼 기록
- 에이전트와 함께 일하는 방법

==현실의 문제를 AI로 해결하는 과정==을 있는 그대로 남기려고 합니다.

## 어떻게 만들었나

| 부분 | 쓴 것 |
| --- | --- |
| 사이트 생성 | Hugo + PaperMod 테마 |
| 디자인 | 설코딩 디자인 시스템(색·글꼴·형광펜) |
| 배포 | GitHub에 올리면 Cloudflare Pages가 자동 배포 |

글은 마크다운 파일 하나로 씁니다.

```bash
hugo new content posts/<글-주소>/index.md
```

> [!tip]
> 이 블로그는 에이전트가 초안을 만들고 사람이 다듬습니다. 만드는 과정도 차차 글로 풀겠습니다.
